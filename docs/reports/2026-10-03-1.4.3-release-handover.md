# Kingfisher 1.4.3 release handover

Completed on 2026-10-03. Release: [v1.4.3](https://github.com/mardakurt/kingfisher/releases/tag/v1.4.3).

## Identity and scope

The certified stable Apple Silicon package is **1.4.3, build 1055**, built from clean, pushed master at `b9a155feb7125774d85f9774c1f3dfb6c6510436`. The app and DMG are Developer ID signed, notarised and stapled. The public download is `Kingfisher-1.4.3-arm64.dmg`, **194248307 bytes**, SHA-256:


The public DMG was downloaded independently, matched against the local certified bytes, mounted and verified with expected version and source commit. Six immutable release assets were uploaded to a fresh draft before publication: DMG, ZIP, signed Sparkle appcast, legacy update feed, checksums and release manifest. No published asset was replaced. The descriptor was updated only after public-byte verification.

The shared application adds Explorer rating classes and board arrows, Library position/annotation filters, collection players/tournaments, online game downloads, Preparation Costly moves, licensed player photos and puzzle analysis help. See [release notes](../release/1.4.3.md). DGT and ChessBase's proprietary products remain outside this release.

The continuation changed only three E2E files before packaging. Keyboard traversal now derives its tab budget from controls instead of stopping one tab before My games; Comment selectors are exact after the new Commented annotation option made them ambiguous. The old keyboard test and a deliberately broken focus path both failed as expected. No application behaviour was changed by these corrections. The incoming history contains 14 commits after `5c96643`, rather than the handover's claimed 17; all were preserved. The user's comparison images were preserved and excluded locally from Git.

## Coverage limits

- Firefox never reached a page: both cached and freshly downloaded official browser builds failed at launch with profile/sandbox errors. Full Firefox/WebKit certification is not claimed.
- Remote full-Chrome [run 37117614191](https://github.com/mardakurt/kingfisher/actions/runs/37117614191) reached 409/474 without assertion failures before the 60-minute job cap cancelled it. This is incomplete CI evidence, not a passing remote E2E gate. The local full run above completed.
- The optional companion-service benchmark was skipped because its token was not configured; the in-process SQLite benchmark ran.
- A quarantined/offline GUI first-launch check was not performed. Gatekeeper, signatures and stapled tickets were verified separately. Windows, Linux and Intel Mac packages were not certified.
- The incoming agent's 300-game export and live Lichess/Chess.com/Wikimedia tests are its reported evidence; this continuation did not repeat every upstream round trip. Existing real-engine, packaged and browser specs ran as recorded above.
- Research remains opt-in; the five-player usability study is pending. No full ChessBase parity claim is made.
