# Kingfisher 1.4.4 release handover

Completed on 2026-10-03. Release: [v1.4.4](https://github.com/mardakurt/kingfisher/releases/tag/v1.4.4).

## Identity and scope

The certified stable Apple Silicon package is **1.4.4, build 1069**, built from
clean, pushed master at `f5f751cebbbd9982c68db766df27dfdca79813cc` — the same
commit Vercel serves. The app and DMG are Developer ID signed, notarised and
stapled (DMG submission `decda8f2-131a-48b8-89f7-0ef96c30838a`). The public
download is `Kingfisher-1.4.4-arm64.dmg`, **193950081 bytes**, SHA-256:

```text
6820a49f19fa42d944241bc300408a2b34dcc5aaac3bbf215de9a01a0cce6876
```

The six assets were uploaded to a draft, downloaded back and checked against
`SHA256SUMS` (DMG byte-identical to the certified file) before the release was
made public and latest at 15:05:29 UTC. No asset was replaced.

What 1.4.4 contains, and why, is in [the release notes](../release/1.4.4.md)
and [the comparison](../product/chessbase-mac-comparison-1.4.4.md): the
annotation bar, the Library's Opponent filter, the installed reference packs
as Library sources, top games that name each game's move and open at the
position, strongest players and last-played columns, database folders, and a
switch for the Wikimedia photos, with the defects using them turned up.

## Coverage limits

- Firefox and WebKit were not run; only Chrome is certified.
- The 30-minute wall-clock soak and the packaged resource-leak soak were not repeated for this release.
- A quarantined GUI first-launch (double-click from a browser download) was not performed; Gatekeeper, signatures and stapled tickets were verified separately.
- Windows, Linux and Intel Macs are not certified.
- ChessBase for Mac was not run; it is unreleased. No parity is claimed.
