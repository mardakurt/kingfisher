## 3. Tests that could not fail, and were fixed

- The companion frequent-players test passed with `COUNT(*)` for
  `COUNT(DISTINCT …)`: import already stores one row per (game, position,
  move), so the query now uses `COUNT(*)` and the test says what it pins.
- The top-games walk's stopping rule was not exercised by a 400-game corpus;
  600 lopsided games were added so that a first-page-only mutation fails.
  (That code was later removed with the duplicate contents page.)
- The sidebar "in view" test measured against the row's own group list and
  passed without the fix; it now measures the scrolling list.
- The sidebar reload-race test passes with or without the guard; it says so,
  and guards the behaviour rather than claiming the race.

Every other new test was shown to fail with its fix reverted.
