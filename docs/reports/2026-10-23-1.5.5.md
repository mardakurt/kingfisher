# 2026-10-23 — 1.5.5: entering, replaying and reading games

What was audited, found, fixed, added and run, from `4e0e2280` (1.5.4) to
the commit that adds this report. The implementation account was recovered
from the previous session's handoff and draft. The validation below was
run again during closure; where something was not run, it says so.

Closure host: macOS 27.0.1, Apple Silicon, Node 24.14.0.

## What was asked

"The app seems complete; it is not. Find what to enhance, fix it, and at the
end of the session give me version 1.5.5 with a lot of fixes, enhancements
and maybe added features."

## How it was looked for

- The application was used as a player would, in the built-in browser at
  1440×900, 375×812 and 320×640: analysis, a clocked game imported, Studies
  (a study and a chapter created), Repertoire (a line added as Black),
  Puzzles, Review, Openings, the empty states.
- Domain code was probed with throwaway tests: twenty-two PGN notations
  through the parser, ten FENs through the FEN reader, the scheduler at
  different hours and in four time zones.
- The ledgers (`not-built.md`, `parity-ledger.md`, the design notes) were
  read for items recorded as open, and each was checked against the code.

## Found and fixed

- **The promotion picker could not be used from the keyboard.** It chose on
  pointerdown only, and lost its own focus: a click-click move commits on
  pointerdown and the browser's mousedown then moved focus to the page.
- **Long algebraic PGN imported with no moves** (`1. e2-e4` read as a move
  to e2), and figurines, `O–O` with a typographic dash, `nf3` and `½-½`
  each cut a game short.
- **Windows-1252 PGN lost every accented name** ("Müller" → "M�ller"), in the
  browser and in the companion: both decoded every file as UTF-8, silently.
- **Spaced repetition counted a day as 24 hours**, so a card reviewed late
  was not due the next morning; "1 months"; the Daily endgame pick turned
  over at UTC midnight.
- **A study's name was cut to "Sicilian …" at 1440 px**: the header measured
  its room before the name arrived and never again.
- **Studies with no chapter showed another game's moves** in its notation.
- **Shortcut hints disagreed with the bindings**, including a wrong hint for
  moving a variation up. The palette, notation menu and board controls now
  read the person's live binding; initial server labels remain hydration-safe.
- **The packager pinned an older Electron independently of the dependency.**
  Updating the dependency alone would still have shipped 44.2.0. A new
  package/configuration consistency check failed against that old pin; both
  now name 44.5.0, and the downloaded binary reports that version too.
- **On a phone the controls under the board clipped** once Play and Type were
  added; now 32 px steps on one row, wrapping at 320 px.
- **A recorded "open defect" that never existed**: reference packs were said
  to file a `*` game as a Black win; the scan has rejected every undecided
  game since the builder was written. The design note and the ledger now say
  so. A stale ledger row ("shortcut remapping missing") was removed — it has
  existed since Phase 10.

## Added

Typed moves and whole lines (`T`); paste a PGN or FEN anywhere to import;
both clocks at the move on the board; time per move under the evaluation
graph; the engine's own win/draw/loss (`UCI_ShowWDL`); play a line through
(`P`); a link that opens a line (`?moves=`); import only the games wanted
(rating, player, years); optional move sounds made with Web Audio; a refused
FEN offered back without impossible castling rights; copy an engine line as
text; the line's link from a move's own menu.

## Not done, and why

- The user authorized pushing, web deployment and publication of the signed
  Mac 1.5.5 release during closure. Publication follows the source, packaging,
  trust and acceptance gates; no public release claim is made by a source
  test passing alone.
- The installed application and the public descriptor both still name
  1.5.4 build 1237. The 1.5.5 source changes are Mac-facing and require a
  newly built and certified package before a Mac release claim.
- Mac release preflight found the Developer ID identity, notarization
  credentials, tools and disk space available. It failed on the uncommitted
  visual baselines and local commits ahead of `origin/master`; it was run
  before the baseline commit. A stable build was not attempted past that gate.
- The full four-engine suite was not run. The initial Firefox launcher
  failures and failed headed probe are retained as diagnostic evidence;
  later isolated-home visual and feature checks are recorded separately.
- Linux visual comparisons are pending the repository's workflow; the local
  Docker Desktop and OrbStack daemons were unavailable. Linux snapshots were
  not replaced with macOS captures.
- Selective PGN filtering does not cover the companion's separate large-file
  import path; that boundary is recorded in `docs/product/not-built.md`.
