# Interface prototype — five-player study

This is an unrun study protocol, not an acceptance result. Recruit five strong
players who regularly analyze annotated games and compare reference sources.
Record the exact commit and packaged build, macOS, display dimensions, input
source, engine and accessibility configuration for each session. A facilitator
may introduce the task but must not guide its completion.

Use an actual annotated Capablanca game distributed with Kingfisher, the
installed Starter Reference, and three real engine candidates. Do not replace
real evidence with synthetic numbers. Start with a disposable profile and keep
participants' own data out of the test.

1. Open the game and choose Research workspace. Find a specified annotated
   move, identify the named reference population, run three candidates and
   preview a complete principal variation.
2. Resize both panes using the keyboard. Navigate notation and engine controls,
   open and dismiss menus, and return to the document without losing the move.
3. In Library, select a game, open filters, confirm the preview remains visible,
   navigate rows with arrows/Home/End, and open at the previewed move.
4. In Preparation, search a real player, identify the source and denominator,
   change a filter, create a session and find its actions again.
5. Repeat core actions in light/dark mode, 1280×720 and 900×600, and full screen.
   Confirm narrow folding preserves the position and all tools are reachable.
6. Enter and edit comments using the participant's macOS input source. For a
   VoiceOver session, verify position context, current move, selected row, pane
   boundaries and controls. Listen while the engine searches to check that
   updates do not overwhelm speech. Record spoken observations explicitly.
7. Save authored work, quit and reopen the package, and confirm it survives.

For every task record completion without assistance, elapsed seconds, errors,
interventions, and a 1–5 readability rating. Preserve failed attempts. Suggested
columns: participant, task, build, theme, window, completed unaided, seconds,
errors, intervention, readability, notes. Do not identify participants publicly
without their permission.

Acceptance: at least four of five complete the core workflow unaided. Report
all five individual results and the actual denominator, alongside task times and
ratings. An automated script is not a substitute for a player.

Reconsider a selected native surface only if a recurring essential macOS behavior
remains blocked after a focused Electron fix and an AppKit prototype resolves it.
Confusing hierarchy, clipped controls and missing focus are component defects
until evidence shows otherwise. No migration may duplicate chess state or
strand the existing desktop profile.
