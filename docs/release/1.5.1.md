# Kingfisher 1.5.1 — puzzle feedback and correctness fixes

Puzzles give clear correct/incorrect feedback after a move. A wrong move is
briefly shown, then taken back so you can try again from the same decision.
The answer stays hidden until you request it. You can also retry interactively
after revealing the solution. A wrong move or hint records one unsolved rated
attempt; finishing afterwards is practice and does not change that result.

Storage-status backups include portable preferences. Backup merges handle
journal entries with matching fingerprints, and profile edits preserve favourites.
Explorer filters and source comparisons respect the capabilities of each source.
Repertoire coverage and tablebase-perfect defence explicitly handle missing
reference evidence. Chess validation, imports, collection operations and engine
result handling reject invalid or incomplete evidence.

Validation results and the exact tested package are recorded in
[the closure report](../reports/2026-10-08-closure.md). The source version does
not change the public download descriptor; packaged 1.5.0 acceptance is separate
from validation of these 1.5.1 source changes.
