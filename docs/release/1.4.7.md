# Kingfisher 1.4.7 — dependable analysis and Library navigation

Release candidate, 2026-10-04. Publication and packaged acceptance are pending.

- The evaluation bar keeps its black/white bands opaque between moves. While
  the engine catches up, the previous geometry is held with an ellipsis instead
  of flashing grey or presenting an old score as current.

- Engine startup can be stopped immediately. Unavailable engines can be retried,
  and failed startup, configuration or search sessions are disposed before retry.
- Rapid navigation cannot revive a stopped search or attribute old analysis to
  the current position, including returning to a previously analysed position.
- MultiPV, threads, memory and search-limit changes update active unrestricted
  searches. Stopped engines stay stopped; candidate-search restrictions remain
  intact. Resource labels show the applied session configuration, and choosing
  One engine releases the secondary session.
- Switching Library databases clears old search results, including move-level
  searches. Obsolete companion HTTP requests are cancelled, and companion filters no
  longer also query My games.
- Direct FEN links keep their position if a route payload fails. URL cleanup is
  local, preserves other query parameters and the fragment, and permits handing
  the same FEN to the mounted route again.
- A slow game load cannot overwrite a more recent game choice, an intervening
  edit or the workspace after leaving the route that requested it.

No new chess capabilities, account system or corpus were added. Data formats and
backup stores are unchanged. Full evidence and remaining limits are in the
[professional-use stability audit](../reports/2026-10-04-professional-stability-audit.md).
