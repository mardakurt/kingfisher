# Kingfisher 1.4.8 — dependable in Safari, across tabs and on real databases

Fixes found by the professional-use closure audit; each was reproduced first
and is covered by a regression test that fails without it. Full evidence:
[closure working log](../reports/2026-10-04-professional-use-closure.md).

**Your work**

- Safari: an unsaved edit survives leaving Kingfisher by a link or address and
  coming back. Safari kept the page it left frozen in its history cache with a
  storage write open, which lost the edit and stalled every later save behind a
  false "saved".
- Two tabs: a tab reloaded a moment after an edit keeps its own work even when
  another tab is saving at the same time; it no longer comes back showing the
  other tab's document.
- Studies never names a chapter the board does not hold. After a chapter switch
  is cancelled by an edit, the header says what the board holds, and the board
  stays on screen.

**Remote sources**

- Safari: a stalled connection to Lichess, the tablebase, the companion or the
  assistant ends with a named error after its deadline, instead of "Reading…"
  for ever.
- Signed in to Lichess and reopening Kingfisher on Lichess Masters answers the
  position instead of asking you to connect.

**Large databases**

- Games imported from Lichess's own database archives are dated (from
  `UTCDate`); before, they had no date, so date filters, year windows and date
  sorting left them all out. Collections imported earlier keep their missing
  dates; import the archive again into a new collection to date them.
- Sorting a large companion collection by player is immediate (4.8 s → 22 ms on
  578,262 games), and alphabetical regardless of case.
- The Library footer says it is reading while a query runs, not "0–0 of N games".
- Opening or reloading the Library on a companion database no longer says the
  companion is not connected while it is answering.

**Everywhere**

- Annotation arrows have a clean point and a head clearly wider than the shaft,
  on the board and in exported diagrams.
- Safari: keyboard focus stays inside an open dialog.
- Reopening Kingfisher a moment after quitting waits for its previous instance
  to finish closing, instead of reporting that another program holds its port.
- Firefox no longer logs a Content-Security-Policy violation on every page:
  an unused validation library, which probed for `eval`, left the bundle.

No new chess capabilities, accounts or data formats. Backups are unchanged.
