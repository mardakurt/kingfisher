Kingfisher 1.0 is the first public stable release. Web is **stable**.
macOS is **Preview** (signed, not notarized) while the maintainer waits for
a Developer ID Application certificate from Apple.

## What Kingfisher is

Kingfisher is a local-first chess workstation for serious players. It
combines opening research across separate evidence sources, native chess
engines, large personal databases, study and repertoire work, and player
research in one workspace that runs both in the browser and as a native
macOS application.

## What 1.0 includes

- **Opening research.** Compare elite OTB broadcasts, recent theory and
  high-rated online play side by side. The Explorer keeps each source's
  provenance, licence, and game count separate — no silent population
  merging into a single "truth" score.
- **Theory Book.** 3,810 named opening positions with ECO codes.
- **Engines.** Stockfish 18 in the browser (sandboxed, threaded). On
  macOS, native Stockfish, Berserk, Halogen, Koivisto, Obsidian,
  PlentyChess, Stormphrax, Viridithas and Lc0 — each digest-verified
  on install.
- **Databases.** Attach a personal PGN database or import a Lichess
  archive. Index to position, player, structure, claim, and game
  headers. SQLite under the hood on desktop, IndexedDB on web.
- **Players.** Search by name, open a profile, jump straight to a
  recent game or an opening the player favours, then into Preparation.
- **Studies and Repertoire.** Save analyses, build a repertoire, watch
  your move tree grow. Local-first; nothing is uploaded.
- **No account. No telemetry. No subscription.** MIT-licensed source.

## Try it

1. Open <https://kingfisher-chess.vercel.app/>.
2. Click **Launch Kingfisher**.
3. Play a few moves. Start Stockfish. Open the Starter Explorer.
4. Optionally install an additional reference pack (Elite OTB, Recent
   Theory, or High-Rated Online) from the Databases page.

## Download for macOS

Apple Silicon, code-signed. The binary is not notarized yet — this is the
**Preview** channel. To install:

1. Download `Kingfisher-1.0.0-arm64.dmg` from this release.
2. Open the DMG and drag **Kingfisher** to Applications.
3. On first launch, right-click the application in Finder and choose
   **Open** from the context menu. Confirm the Gatekeeper prompt.

The macOS channel is honest about the missing notarization so a new user
is never surprised by an unsigned-binary warning. Notarization is a
post-1.0 follow-up as soon as a Developer ID Application certificate is
available.

## Privacy

- No analytics on the landing page, in the web app, or in the desktop
  app.
- No telemetry, no account, no upload of your studies, repertoire, or
  preferences.
- Reference data installs once and is read locally.
- The diagnostic report redacts OAuth tokens, session tokens, and
  personal paths before display or copy.

## Known limitations

- macOS Preview (not notarized) — see installation above.
- Update check is manual: **Kingfisher → Check for Updates…** in
  the macOS menu, or **Settings → Check for Updates** in the
  app. There is no background poller and no auto-restart; the
  install is gated on the user explicitly consenting.
- macOS Intel DMG exists but has not been manually verified on
  Intel hardware; it is not the primary download.
- Windows and Linux desktop builds are not part of this
  release; the macOS application is the supported desktop
  channel.
- Bundled reference data starts in 2020; earlier broadcasts are
  available through the Lichess Masters / Online Explorer
  sources.
- Chess960 is not supported.
- Local Syzygy tablebase probing requires the user to provide
  the tablebase files.

## Reporting a problem

- **Website footer → Report a problem** opens a pre-filled GitHub
  issue.
- **In the app:** _Help → Copy support information_ or _Copy diagnostic
  report_, then paste into an issue.
- **Direct:** <https://github.com/mardakurt/kingfisher/issues>

No account is required beyond a free GitHub account to file an issue.
