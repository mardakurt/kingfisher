# Kingfisher 1.3.0

Released 2026-09-26. The largest release since 1.0: Kingfisher is redrawn as
a quiet Mac document window, the landing, the icon and the Mac application
share one design with the Studio, six workflows ChessBase users rely on
arrive, and Phase 85 adds large databases through the companion, an indexed
move search, dated and rated reference packs, deep analysis that survives
the night, and remote engines on the player's own machines. Everything from
Phases 76–85 that the web has had since 1.2.6 reaches the Mac application in
this release. The web application has the same source and ships the same
code.

## What changed since 1.2.6

The user-facing list is the 1.3.0 entry in
[`CHANGELOG.md`](../../CHANGELOG.md#130--2026-09-26). In short:

**The design (Phases 82–84).** A white workspace, a grey source-list sidebar,
the platform's own typeface, one blue accent, the Studio board, the notation
beside the board, working tabs, the Library, a preparation report and a
Databases grid. The evaluation bar is framed like the board so it reads in
the light theme. The landing, the public pages, the app icon (the bird on the
Studio board, on Apple's icon grid) and the disk image are drawn from the
Studio's own tokens.

**The Mac application.** The window follows the Light/Dark choice made in
Kingfisher — its own sheets and menus, Sparkle's window and the colour shown
before the page paints — and the menus carry the application's commands:
New Tab ⌘T, Close Tab ⌘W (the window is ⇧⌘W), Show Next/Previous Tab ⌃Tab
and ⇧⌘]/⇧⌘[, Duplicate Tab, New Analysis ⌘N, Import ⇧⌘I, Toggle Sidebar
⌃⌘S, Command Palette ⌘K, Keyboard Shortcuts, View → Appearance, a Go menu and
a Dock menu. The "Kingfisher was updated" notice after this update is drawn
in the Studio's surface; before, it fell back to a navy strip in the light
theme.

**ChessBase-level workflows (Phase 84)**, compared workflow by workflow in
[`docs/product/chessbase-parity-audit.md`](../product/chessbase-parity-audit.md):
merge games into one tree; scan any collection against a repertoire; the
Lichess cloud evaluation, asked for and labelled; a position's history;
the Library over any database; questions inside a chapter, solved with
Training's control and printed as a worksheet.

**The Phase 85 continuation:** large PGN, compressed PGN and ChessBase files
stream through the companion; material, theme and route searches use a compact
line index; reference packs can supply year/Elo history to the Opening Report;
deep analysis resumes after reload and relaunch; labelled Monte Carlo,
collection-wide departure, question points/timers, new ChessBase export and
file-based engine-evidence exchange are included. The public-domain annotated
set contains fourteen checked Capablanca games and is described as a book, not
as a master corpus.

**From Phases 76–81**, first on the Mac in this release: reading ChessBase
CBH/CBV files, the scoresheet, publishing a study, writing engine evidence
into a game, tags and search, the surprise finder, similar games, the
position page, the daily session, the season, recurring facts in Review, and
the search mask.

**Phase 85 on the Mac.** Remote engines on another of the player's machines,
paired by a code and carried over TLS with a pre-shared key
(`docs/design/remote-engines.md`); a 783,262-game High-Rated Rapid &
Classical online reference; Elite OTB with each position's history by year
and Elo class; deep analysis that keeps running with the window closed,
survives a sleep and a quit, and resumes from its checkpoint.

**Fixed:** a move played in a study chapter just before a reload could be
lost while the header said "Saved"; ⌘Q did nothing while a deep analysis ran;
relay dates written day first became years such as 1508 in the broadcast
packs; a Library move search that failed could read as "none found"; the
icon drew the board inset in a navy border instead of filling its rounded
square.

**Data:** schemas v19 (the round journal), v20 (tags on studies and chapters)
and v21 (question sittings, persistent deep analyses and imported evaluation
files) — a Mac profile upgrades its IndexedDB from 1.2.6's v18 on the first
launch of 1.3.0, as every schema change does; `npm run desktop:upgrade` is the
check. The companion inside the
bundle gains the search mask's header fields.

## Installing and updating

Download `Kingfisher-1.3.0-arm64.dmg`, open it, drag Kingfisher to
Applications, and double-click. An installed 1.1.8–1.2.6 is offered 1.3.0
through Sparkle's own window (_Kingfisher → Check for Updates…_); an
installed 1.1.0–1.1.7 is offered it by the engine those versions shipped
with (the release carries `latest-mac.yml` for it). The work in
`~/Library/Application Support/kingfisher-desktop/` is not touched by the
update. macOS caches Dock icons: if the old icon stays in the Dock after
the update, removing Kingfisher from the Dock and adding it back shows the
new one.

## Verification

The exact bytes the landing offers — size, SHA-256, build number and
commit — are in `src/release/macos-download.json`; `npm run
desktop:public:verify -- --landing --full` downloads them from GitHub and
checks the hash, the signature and the stapled ticket. The commands run for
this release and their results are recorded in
[`docs/reports/phase-85-handover.md`](../reports/phase-85-handover.md).
