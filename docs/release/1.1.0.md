# Kingfisher 1.1.0

Released 2026-09-12. The first Kingfisher signed with a **Developer ID**
certificate and **notarised by Apple**: the DMG opens and the application
starts with a normal double-click. Web and macOS ship the same
application at the same version.

Apple Silicon (arm64) only. **Requires macOS 13 (Ventura) or later** —
the release page and the 1.1.0 bundle itself state macOS 11, which was
wrong: the Electron 44 runtime inside the application does not start on
macOS 11 or 12. Corrected in the documentation in Phase 49; the bytes of
the release are unchanged.

## What is new since 1.0.0

- **Trusted macOS build.** The application, every nested helper and the
  disk image are signed with `Developer ID Application` (team
  `3B5CYF9DQ4`) with the Hardened Runtime; Apple's notarisation ticket is
  stapled to both. Notarisation is Apple's automated malware screening,
  not an endorsement.
- **A packaged application that contains the application.** Every build
  after the polished-DMG work had shipped without its web server and
  companion; the bundle's required contents are now one list, enforced
  before signing, and the built application is launched before a DMG is
  made from it.
- **Check for Updates works.** A native panel under _Kingfisher → Check
  for Updates…_; download, SHA-512, save barrier, macOS's own update
  engine, relaunch. Nothing is checked in the background.
- **Game Review**, the two-engine comparison with redrawn best-move
  arrows, a titled-player roster of 8,339 GM/WGM/IM/WIM players from
  Wikidata, opening search that answers to the names players use (QGD,
  KID, Berlin, Sveshnikov…), Halogen 16.8.0, real three-piece Syzygy
  tables, and the companion and desktop-reliability fixes listed in
  [`CHANGELOG.md`](../../CHANGELOG.md#110--2026-09-12).

## Upgrading from the 1.0.0 preview

The 1.0.0 preview predates the updater and is signed with a different
identity, so it cannot update itself. Quit it, replace it in
Applications with 1.1.0 by hand, and open the new one. Studies,
Repertoire, Training, Recent work and Settings live in
`~/Library/Application Support/kingfisher-desktop/` and are kept.
