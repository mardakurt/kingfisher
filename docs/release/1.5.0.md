# Kingfisher 1.5.0 — the release a long session was run on

1.5.0 closes the last known defects from the professional-use audit and
raises the Mac requirement to what has actually been tested. It adds no new
chess features. Full evidence: the
[stability audit](../reports/2026-10-04-professional-stability-audit.md) and its
[working log](../reports/2026-10-04-professional-use-closure.md).

**Requirements**

- The Mac application now requires **macOS 14 (Sonoma) or later** on Apple
  Silicon. macOS 14 is the oldest version a packaged Kingfisher has been run
  on; macOS 13 was declared but never tested, so it is no longer promised.
  On macOS 13, keep 1.4.9 — it is not offered this update — or use
  Kingfisher in the browser at <https://kingfisherchess.app/analysis>.

**Large databases**

- Sorting a companion collection by Date or Opening is instant after the
  first time. The first sort builds the index once — 0.9 s on a 1,048,440-game
  collection, where every Date sort used to take 10.4 s — and it stays built.

**Studies**

- Reloading with slow storage no longer highlights a study's first chapter
  before the chapter it actually restores.

**The companion**

- A request that lands on a connection the companion has just closed (seen
  during very large imports) is asked once more instead of reporting the
  companion as not reachable. Requests that start an engine or an import are
  never repeated.

No new accounts, data formats or permissions. Backups are unchanged.
