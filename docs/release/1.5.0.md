# Kingfisher 1.5.0 — your openings, rating classes, and macOS 14

**macOS 14 (Sonoma) or later is now required.** macOS 13 was never tested.
Mac users on macOS 13 keep Kingfisher 1.4.9 or use the web app at
<https://kingfisherchess.app/analysis>, and are not offered this update.

**Chess work**

- Explorer rating class, with each source's stated rule beside the results
  (My games, companion SQLite collections, Lichess's native buckets); sources
  that cannot filter by rating say so.
- _Your openings_: a repertoire overview that lists White and Black together,
  counts recorded intended decisions and opens their named positions.
- The PGN `Title` tag appears in the game header, and a collection has a title
  index to browse and open the games carrying a selected Title.
- Navigation from metadata links opens a fresh Library view.
- Dependencies: sharp 0.35.5, source-map-js 1.2.2.

**Fixes**

- The Mac application requires macOS 14, the oldest version it has been run on.
- Sorting a large companion collection by Date or Opening builds its index
  lazily on first use and is instant afterwards.
- A reload with slow storage no longer highlights the first chapter of a study
  before the chapter it restores.
- A companion GET that lands on a connection the companion just closed is
  asked once more; requests that start something are never repeated.
- _Review repertoire_ stays in the header row; _Your openings_ comes after it.
- Menus opened near the edge of a phone-width window stay inside the window.

No new accounts, data formats or permissions. Backups are unchanged.
