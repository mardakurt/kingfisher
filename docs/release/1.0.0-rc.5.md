# Kingfisher 1.0.0-rc.5

Kingfisher's public preview is live.

| Surface       | Address                                           |
| ------------- | ------------------------------------------------- |
| Web app       | <https://kingfisher-chess.vercel.app/>            |
| Landing page  | <https://mardakurt.github.io/kingfisher-data/>    |
| macOS preview | `Kingfisher-1.0.0-rc.5-arm64.dmg` on this release |

## What changed

- Added a direct, accessible `/settings` route to the web application.
- Published the source and data repositories and the GitHub Pages landing page.
- Connected every current launch link to the production Vercel origin.
- Added production-safe browser-engine installation to the Vercel build.
- Hardened the repeatable secret and personal-path scan without suppressing
  unknown findings.
- Refined the landing page across phone, tablet, laptop, and large desktop
  viewports and reduced its product imagery with WebP sources.

## macOS preview

The Apple Silicon application is signed and its checksum is published, but it
is not notarized. Follow the included
[installation guide](https://github.com/mardakurt/kingfisher/blob/master/docs/release/install-macos.md),
including right-clicking the application and choosing **Open** on first launch.

## Verification

The release gate, production routes and headers, threaded browser Stockfish,
all three public reference-pack installs, browser persistence, the public-link
gate, and packaged macOS smoke/restart checks were run before publication.
