# Kingfisher 1.4.4 — the Library, the reference and the notation, after ChessBase for Mac's recordings

Release notes, 2026-10-03. The comparison behind the list, with the evidence
for every number, is
[`chessbase-mac-comparison-1.4.4.md`](../product/chessbase-mac-comparison-1.4.4.md).

## New

- **Annotation bar** in the Notation header: `! ? !! ?? !? ?!`, a menu of
  the position judgements from +− to −+, comment, and move up / delete
  after / delete from — for the move the board shows.
- **Opponent** in the Library's filters: with a player, the games between
  the two (the colour stays the player's); alone, every game the opponent
  played. In My games, companion databases and the reference, and kept by
  saved queries.
- **The reference in the Library.** Pick an installed reference pack in the
  database menu and search it by player: type part of a name, or name a
  player and an opponent in Filters; every other filter applies to their
  games, which preview, open and can be searched by their moves. A pack
  keeps the moves of a player's newest 300 games and counts the rest; the
  Library says so when it matters.
- **Top games** in the Explorer: the move each game played at the position,
  both ratings, date, ECO, length and event; a click opens the game at the
  position you are exploring.
- **Strongest players** and **Last** columns in the Explorer when it is
  wide: who made the move in the strongest games the pack keeps after it,
  and the latest year the source has it.
- **Folders** on the Databases page: New folder, drag a database onto it or
  use Move to folder; a search looks inside folders.
- **Settings → Database → Player photos** turns the Wikimedia photos off;
  off, nothing is requested from Wikimedia.

## Fixed

- A player filter on a companion (SQLite) database matched nothing when the
  name was typed with capitals, as it is printed.
- Downloaded online games were listed oldest first.
- A player photo's credit link is accepted only when it is the file's
  Commons page, and an image Wikidata has deprecated is never shown.

## Data and privacy

No schema migration: folders share the store that source sets use and are in
every backup. One new preference (`showPlayerPhotos`), on by default. The
privacy page names the switch.

## Not in this release

Frequent players per move (packs keep no per-move player lists), medals and
ChessBase's other editorial data, its courses, magazines, services and cloud
databases, and DGT boards.
