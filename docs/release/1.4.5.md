# Kingfisher 1.4.5 — local video lessons and richer database research

2026-10-03. [Comparison and boundaries](../product/chessbase-mac-comparison-1.4.5.md).

- **Video lesson** in Studies: choose a local video, add timed cues to chapter
  positions, and follow it on the board. Explore freely with Follow off, or
  jump to a cue. Filename and cues travel with PGN and backups; reattach the
  local video after reopening. No video is uploaded or included in backups.
- **Annotator, PGN source and Team** filters in the Library and query builder,
  from the tags the imported game actually carries. Works with My games and
  companion databases; absent tags never become guessed metadata.
- **Frequent players** per Explorer move in My games, with distinct game
  counts from the current filtered population, also readable in a narrow dock.
- **Fixed:** the strongest-player sample now verifies the actual move from
  the position, so a different move order into its result cannot credit the
  wrong move. Rapid study chapter switching now saves pending edits before
  opening another chapter. Reload recovery compares all authored content,
  including cues, annotations and headers, rather than only moves and comments.
- **Fixed in the Mac app:** Save query could not ask for a name because
  Electron refuses browser prompts. The shared naming dialog now works in
  either application identity and displays storage failures inline.
- Next.js and its ESLint package updated to **16.3.8**; both Dependabot PRs
  merged, including desktop brace-expansion patches.

Local videos are an open-format alternative, not a proprietary Fritztrainer
reader or course catalogue. Reference-pack player frequencies, full pack-wide
search, licensed editorial content and ChessBase's hosted services remain
outside these additions. File exchange and no DGT remain the owner's choices.

No new persistence store or schema migration. Browser-supported video formats
depend on the browser's codecs. Lesson video files must be retained separately
from the portable workspace backup.
