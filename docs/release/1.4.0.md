# Kingfisher 1.4.0 — Research workspace

## What changes

- **Research workspace:** a full-height board beside notation, a named reference
  population and compact engine candidates. Full principal variations remain
  available through Preview and Insert; narrow windows fold tools into tabs.
- **Research readiness:** the Analysis toolbar's information button shows the
  selected engine and its actual reported identity. Run a short search at the
  current position without replacing an active search. A handshake is not
  reported as a successful search, and a retained result from another position
  is not current evidence.
- **Reference population:** readiness queries the same provider and cache as the
  Explorer, with the global rating/year filters. It names the population,
  reports connection/authentication errors and offers an explicit switch to an
  installed offline source. A valid zero-game answer stays distinct from failure.
- **Work protection:** saved chapters, saved drafts, unsaved changes, failed
  writes and revision conflicts remain different states. The last successful
  backup is separate from the latest attempted backup. Local snapshots share
  the profile's storage; export a portable backup for a separate copy.
- **Keyboard and readability:** both dividers support keyboard resizing;
  notation keeps the selected move visible with a bounded tab sequence;
  Library filters preserve the selected game's preview; Preparation keeps
  session actions in its toolbar. Board coordinates and shared light/dark
  controls use consistent contrast, corners and elevation.
  Dialog buttons no longer pass navigation or annotation keys to the board behind them.
  Settings, Save to study and the command palette replace readiness
  rather than stacking over it, preserve an already open editing form, and return focus
  to its invoking control. Command-palette Escape respects input composition.
- **Engine startup:** names the selected engine rather than Stockfish. Native
  catalogue availability follows published platform builds; unsupported engines
  do not fall back to a differently named Stockfish process.

## Compatibility and scope

Electron and the shared Next.js/React application remain. Existing layouts are
preserved, and Research is opt-in under Layout. There is no new chess state,
board renderer, persistence schema or desktop origin. Autosave, draft recovery,
revision conflicts, portable backups, source provenance and separate reference
populations keep their existing contracts.

This version is being prepared for a public release. Until publication and byte
verification complete, `src/release/macos-download.json` continues to name the
previous stable 1.3.3 download. Release validation and any outstanding human
VoiceOver, input-method and five-player study evidence are recorded separately;
automated accessibility assertions are not user observations.
