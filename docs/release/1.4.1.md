# Kingfisher 1.4.1 — research handoffs, database updates and analysis checkpoints

Release notes, 2026-10-02. The Apple Silicon candidate application is Developer ID
signed and notarized by Apple. The DMG’s separate Apple submission is pending,
and the release remains unpublished. Version 1.4.1 was bumped after the roadmap
implementation changes; public publication and byte verification are recorded
in the [validation report](../reports/2026-10-02-chessbase-roadmap-validation.md).

- Opening Report offers a source-specific opening survey: choose depth and
  branch width, generate a bounded legal variation tree and copy PGN with
  recorded game counts, source identity and explicit limits. It surveys
  practice; it does not recommend an optimal repertoire.
- Copy the Opening Report as Markdown, preserving position, time,
  source separation, sample denominators and unavailable evidence.

Surveys stop at forty source queries, reuse transpositions and stop repeated
positions. Cancelling retains explicitly partial PGN; closing aborts the job.
Survey generation preserves the current analysis document and repertoire.
Choose intended answers and save their paths as a study chapter with training
questions and dated source counts. Online sources still
require their normal authentication/connectivity; installed sources work offline.

The [research and proposed next increments](../product/chessbase-roadmap-2026-10-02.md)
explain the ChessBase comparison and why data quality, real-scale acceptance
and integrated preparation remain priorities. This increment does not establish
full ChessBase parity.

- Large-file imports can create compact collections in a chosen external-drive
  directory, set a disk budget and select PGN games by both-player rating and
  explicit BOT tags. No decompressed temporary PGN is written.
- Large imports can continue while their dialog is closed. Active/recent jobs
  are recoverable after renderer reload while the companion remains running;
  competing maintenance is refused. File imports are serialized per companion.
- Optional archive SHA-256 verification precedes game writes. Incremental
  imports into existing collections record newly inserted IDs transactionally;
  rollback preserves older records and duplicates without a full corpus copy.
- Source ledgers expose supplied licences and measured annotation, evaluation,
  date and rating coverage. Expert authorship is not inferred from comments.
- Repertoire inbox can check recent source evidence at up to 40 positions;
  changed evidence reopens reversible decisions.
- Playout experiments record seeds, reported engine identity and requested
  budgets, checkpoint completed games in portable study chapters, resume from
  a saved chapter and export JSON evidence. Wall-clock searches may vary.
- Analysis jobs export their raw budgets and checkpoints. Independent
  ChessBase fixtures and a six-task comparison protocol can be generated.

A 10M corpus certification and independent comparisons remain separate open
acceptance gates; this source increment does not claim complete ChessBase parity.

Repeated error notices collapse into a bounded stack; their text no longer
blocks clicks on the board, and Dismiss remains interactive.
