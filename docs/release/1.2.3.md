# Kingfisher 1.2.3

Released 2026-09-20. The dock's More menu lists every tool again, the
engine selector says what is true for the machine it runs on, and the
landing-page skip has a switch in Settings. The web application has the
same source and ships the same code.

Apple Silicon (arm64), **macOS 13 (Ventura) or later** — the floor of the
Electron 44 runtime the application is built on. Signed with a Developer ID
certificate and notarised by Apple, ticket stapled to the disk image and the
application.

## What changed since 1.2.2

The user-facing list is the 1.2.3 entry in
[`CHANGELOG.md`](../../CHANGELOG.md#123--2026-09-20). In one paragraph:

The one-row tool strip that 1.2.2 introduced clipped its own More menu
to a single item, so the tools folded under it could be reached only by
pinning everything before them; the row now clips sideways only, and
the menu hangs below it in full. The engine selector's note after each
native engine is decided by one rule from the machine the page runs on:
inside the Mac application it reads "needs the companion" or
"Windows only" as before, and on the web it says what is true for that
visitor rather than pointing at a platform they do not have. Settings →
Workspace gains "Skip the landing page", the choice the public landing
offers a returning browser, so it can be turned on or off from inside
the Studio; the Mac application hides it, because it never loads the
landing.

Nothing under `desktop/` changed; the Sparkle feed, the notarisation
pipeline and the release machinery are as in 1.2.2.

## Installing and updating

Same as 1.2.2: download `Kingfisher-1.2.3-arm64.dmg`, open it, drag
Kingfisher to Applications, double-click. An installed 1.1.8–1.2.2 is
offered 1.2.3 through Sparkle's own window (_Kingfisher → Check for
Updates…_); an installed 1.1.0–1.1.7 is offered it by the engine those
shipped with (the release carries `latest-mac.yml` for it).

## Verification

The exact bytes the landing offers — size, SHA-256, build number and
commit — are in `src/release/macos-download.json`; `npm run
desktop:public:verify -- --landing --full` downloads them from GitHub
and checks the hash, the signature and the stapled ticket. The
commands run for this release and their results are recorded in
[`docs/reports/phase-72-handover.md`](../reports/phase-72-handover.md).
