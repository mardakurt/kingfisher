## What is in this release

### Public launch surface

- **A public landing page** at
  <https://mardakurt.github.io/kingfisher-data/>, served from the
  public data mirror. No backend, no CMS, no analytics, no
  fingerprinting. A small static site, mobile-correct, with
  `prefers-reduced-motion` respected.
- **The optional reference data is published.** Elite OTB
  (407,538 games), Recent Theory (44,200 games) and High-Rated
  Online (305,169 games) are installable from the in-app catalogue
  on a fresh profile. The Install button now works.
- **GitHub is open for business.** Issue templates for bug reports
  and feature requests, a label set, Discussions enabled, the
  source repository is public, the changelog is in
  [`CHANGELOG.md`](../../CHANGELOG.md).
- **macOS preview build.** Apple Silicon, code-signed, version
  1.0.0-rc.4. Not notarised — the install guide
  ([`install-macos.md`](install-macos.md)) walks through
  right-click → Open. A Developer ID Application certificate is
  the missing piece that will move macOS from "preview" to
  "release".

### Product

- **Web app and macOS app from the same code path.** The
  application is built once as a Next.js production build, served
  in the browser or by the macOS shell.
- **Source-comparison Explorer.** Each reference source keeps
  its own licence, its own provenance, and its own counts. The
  Explorer never produces a combined "truth" score from a row
  that spans them.
- **Diagnostics that are answerable by somebody who is not
  you.** Settings → Diagnostics now has a _Copy support
  information_ line and a _Copy full diagnostic report_ button.
  URL credentials, query strings and home-directory names are
  redacted at write time, even when the value was never
  registered as a Settings secret.
- **Local log file** at `~/Library/Application Support/Kingfisher/logs/kingfisher.log`,
  rotated at ~1 MB, companion pairing token replaced with
  `[redacted]` before anything is written. Nothing is uploaded.
- **Backup and restore round-trip.** Authored studies, repertoire,
  training, opening files, reviews, preferences, and source
  metadata. Large reference packs are not copied into the backup.
- **Phase 22 data-safety fix.** Two release candidates destroyed
  every study, repertoire and preference on every quit. The fix
  is in `desktop/src/origin.mjs`; the regression test is
  `origin.test.ts` (10 tests). All green on this build.

### CI

The remote CI default has been reduced. The new `ci.yml` is a
typecheck + lint + unit/integration + production build, with
`paths-ignore` for documentation, the landing page, brand
assets, and issue templates. Full Playwright suite, desktop
packaging, engine fleet qualification and the long soak are
moved to deliberately-invoked workflows (`browser-cert.yml`,
`desktop-package.yml`, `engine-build.yml`, `engines.yml`) so that
GitHub Actions minutes are not a per-commit tax.

## Known limitations (carried from the closed beta)

- **macOS preview is not notarised.** A Developer ID Application
  certificate will move the macOS build from "preview" to
  "release". Until then, the install guide is the
  right-click-Open dance.
- **No auto-update.** Open Help → Check for updates, or browse
  the releases page.
- **Windows and Linux build but are unsupported.** They have
  not been launched. Do not expect a Windows or Linux download to
  be the supported path.
- **macOS Intel builds but has not been launched.** The supported
  desktop platform is Apple Silicon.
- **No games before 2020** in any first-party source.
- **Chess960 is not supported, deliberately.**
- **Local Syzygy needs table files the user supplies; the
  bundled probe only goes up to 3 pieces.**
- **Kingfisher refuses to start if its own port is taken.** Pick
  another profile from the profile switcher.

## Reporting problems

- **Bugs** — open an issue with the bug-report template:
  <https://github.com/mardakurt/kingfisher/issues/new?template=bug_report.md>.
  Paste the _Copy support information_ line; attach the full
  diagnostic report if needed.
- **Ideas** — the feature-request template:
  <https://github.com/mardakurt/kingfisher/issues/new?template=feature_request.md>.
- **Chat** — GitHub Discussions:
  <https://github.com/mardakurt/kingfisher/discussions>.
- **Security** — open a private security advisory on GitHub
  rather than a public issue.

## What the maintainer will do with your reports

Each reported defect is either reproducible (and becomes a test)
or it is not. The closed-beta report from the previous two
months became the test suite behind the data-safety fix, the
honest install-failure copy, the support-information export, the
Theory Book return navigation, and several others. That pattern
governs the first weeks of public preview too: every report is
either a test or it is a question about what the product should
do, and either is useful.
