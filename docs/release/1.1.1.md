# Kingfisher 1.1.1

Released 2026-09-13. A maintenance release on 1.1.0: the polish made after
1.1.0 and the corrections found while certifying the product for users
(Phase 49), so that the public Mac application and the web application are
the same build of the same code. The 1.1.0 bytes are untouched; 1.1.1 is a
new release that _Kingfisher → Check for Updates…_ offers to an installed
1.1.0.

| Surface      | Address                                                       |
| ------------ | ------------------------------------------------------------- |
| Web app      | <https://kingfisher-roan.vercel.app/>                         |
| Landing page | <https://kingfisher-chess.vercel.app/>                        |
| macOS        | `Kingfisher-1.1.1-arm64.dmg` on the [v1.1.1 release][release] |
| Data mirror  | <https://github.com/mardakurt/kingfisher-data>                |

[release]: https://github.com/mardakurt/kingfisher/releases/tag/v1.1.1

Apple Silicon (arm64), **macOS 13 (Ventura) or later** — the floor of the
Electron 44 runtime the application is built on. Signed with a Developer ID
certificate and notarised by Apple, ticket stapled to the disk image and the
application.

## What changed since 1.1.0

The user-facing list is the 1.1.1 entry in
[`CHANGELOG.md`](../../CHANGELOG.md#111--2026-09-13). In short: the
evaluation bar keeps saying the same side is better when the board is
flipped; a surname finds the player you mean; the Theory Book locates a
line by its positions; a bare clock comment no longer doubles on each PGN
round trip; the system requirement reads macOS 13; the install page and the
landing describe a notarised application; full screen uses the whole
corner; the command palette has one focus ring; the landing shows a current
capture of the product.

## Verification

The build, the DMG, the signature, the notarisation, the packaged gates,
the browser matrix and the real public update from 1.1.0 are recorded, with
the command behind each, in
[`docs/product/final-certification.md`](../product/final-certification.md).
The exact bytes the landing offers — size, SHA-256, build number and
commit — are in `src/release/macos-download.json`; `npm run
desktop:public:verify -- --landing --full` checks them.
