# Kingfisher 1.2.1

Released 2026-09-19. The Training icon is the knight the web has drawn
since Phase 71, the tour opens from Settings again, the backup
reminder follows the schedule you set, and auto-backups record which
reference packs were installed. The web application has the same
source and ships the same code.

Apple Silicon (arm64), **macOS 13 (Ventura) or later** — the floor of the
Electron 44 runtime the application is built on. Signed with a Developer ID
certificate and notarised by Apple, ticket stapled to the disk image and the
application.

## What changed since 1.2.0

The user-facing list is the 1.2.1 entry in
[`CHANGELOG.md`](../../CHANGELOG.md#121--2026-09-19). In one paragraph:

The Training icon in the sidebar, the Recent page, the tour and the
workspace tool strip is a knight silhouette on the same plinth as the
Endgame king — one icon, one source, checked at 16, 21, 24 and 32 px
in both themes. The Mac 1.2.0 build still drew the previous column-and-
curve icon; this release carries the knight to the desktop. The sidebar
tour, which Phase 61 stopped opening on launch and Phase 62 gave a
Settings link that opened nothing, is mounted again and opens from
Settings → Help only; the preference behind its old "Don't show on
launch" checkbox is retired, and an older profile drops the key on its
next load. The status bar's backup reminder turns amber at the number
of days set in _Auto-backup schedule_ rather than at a fixed seven.
Scheduled and manual auto-backups record which reference packs were
installed (Phase 70), so a restore can say which sources to reinstall.

Web-only, in the same source: the landing's current captures, its
centred header, the complete favicon set, the `/studio` alias and
_Continue in Studio_ for a returning browser (Phase 71). The desktop
shell opens on `/analysis` and never loads the landing. Nothing under
`desktop/` changed; the Sparkle feed, the notarisation pipeline and the
release machinery are as in 1.2.0.

## Installing and updating

Same as 1.2.0: download `Kingfisher-1.2.1-arm64.dmg`, open it, drag
Kingfisher to Applications, double-click. An installed 1.1.8–1.2.0 is
offered 1.2.1 through Sparkle's own window (_Kingfisher → Check for
Updates…_); an installed 1.1.0–1.1.7 is offered it by the engine those
shipped with (the release carries `latest-mac.yml` for it).

## Verification

The exact bytes the landing offers — size, SHA-256, build number and
commit — are in `src/release/macos-download.json`; `npm run
desktop:public:verify -- --landing --full` downloads them from GitHub
and checks the hash, the signature and the stapled ticket. The
commands run for this release and their results are recorded in
[`docs/reports/phase-71-handover.md`](../reports/phase-71-handover.md).
