# Kingfisher 1.2.5

Released 2026-09-20. Three owner reports on the day 1.2.4 shipped, each
about what a Mac user sees in Settings and on the board: engines with no
build for the machine are no longer drawn as switches, the best-move
arrow draws no text on the board when the pointer crosses it, and the
analysis settings a strong player expects — threads, hash, the search
limit, line length, whether the engine follows the board, variation
arrows — are controls rather than a preset's read-only summary. The web
application has the same source and ships the same code.

Apple Silicon (arm64), **macOS 13 (Ventura) or later** — the floor of the

application.

## What changed since 1.2.4

The user-facing list is the 1.2.5 entry in
[`CHANGELOG.md`](../../CHANGELOG.md#125--2026-09-20). In one paragraph:

Settings → Engines in the Mac application listed Berserk, Koivisto and
Obsidian — projects that publish no macOS build — as catalogue rows with
the switch on, above a note saying they are not offered here; the rows are
now the engines the machine can install or has installed, and the note
names the rest. The tooltip the best-move arrow drew on the board under the
pointer is gone — the move, score and depth are in the engine panel and the
legend. And Settings → Engine → Analysis settings gains six controls,
modelled on what lichess.org offers and on what a native engine can
actually be asked: threads and hash chosen directly (a change marks the
preset Custom), the search limit as until-stopped / depth / seconds /
million nodes, the line length in moves (6–24), whether a running engine
follows the board, and variation arrows — the first move of every engine
line, fainter by rank, or the best move only. Each is searchable from ⌘K,
persists, is named in the settings contract and has a browser test that
looks at its effect rather than its storage.

Nothing under `desktop/` changed; the Sparkle feed, the notarisation
pipeline and the release machinery are as in 1.2.4.

## Installing and updating

Same as 1.2.4: download `Kingfisher-1.2.5-arm64.dmg`, open it, drag
Kingfisher to Applications, double-click. An installed 1.1.8–1.2.4 is
offered 1.2.5 through Sparkle's own window (_Kingfisher → Check for
Updates…_); an installed 1.1.0–1.1.7 is offered it by the engine those
shipped with (the release carries `latest-mac.yml` for it).

## Verification

The exact bytes the landing offers — size, SHA-256, build number and
commit — are in `src/release/macos-download.json`; `npm run
desktop:public:verify -- --landing --full` downloads them from GitHub
and checks the hash, the signature and the stapled ticket. The
commands run for this release and their results are recorded in
[`docs/reports/phase-73-handover.md`](../reports/phase-73-handover.md).
