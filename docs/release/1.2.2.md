# Kingfisher 1.2.2

Released 2026-09-20. Opening Kingfisher opens a chessboard; the
evaluation bar is steady between moves and shows the result of a finished
game; the board flips without collapsing; the tool tabs fit one row; the
Companion panel tells the truth about where it is. The web application has
the same source and ships the same code.

## What changed since 1.2.1

The user-facing list is the 1.2.2 entry in
[`CHANGELOG.md`](../../CHANGELOG.md#122--2026-09-20). In one paragraph:

Every launch of the Mac application used to put the last position back
on the board; it now opens on the initial position, and the work is one
click away as _Continue …_ on Recent (a reload, or anything you play in
the session, still comes back by itself). The evaluation bar keeps its
reading while a new search warms up instead of dipping to the middle on
every move, fills the winner's band on checkmate and reads `½-½` on a
draw; the engine panel no longer flashes "No analysis yet" between moves
and says "Checkmate — White wins" where there is nothing to search. The
board flip is a snap with a short fade rather than a rotation that
squeezed every piece to the centre line. The dock's tool tabs fit one
row — icons first, then folding under _More_ — so "More" no longer sits
alone on a second line. The tour draws each section with the sidebar's
own icon. The command palette knows every page and every settings
section. A synced game says "You played White / Black" at every width;
account sync reports its progress and can be cancelled; the Databases
page says what population each source is. In the Mac application the
Companion panel says the companion is built in, and the crash dialog
tells you where your work is.

Web-only, in the same source: the landing's pre-paint Studio redirect,
the full-network Stockfish fetched from its recorded address (the Mac
application has native Stockfish 19 and lists no full build), and the
deployment-storage work (Phase 72). Nothing under `desktop/` changed
except one sentence in the crash dialog; the Sparkle feed, the
notarisation pipeline and the release machinery are as in 1.2.1. From
this release the feed's release notes are a summary with a link to the
full changelog, not the changelog itself.

## Installing and updating

Same as 1.2.1: download `Kingfisher-1.2.2-arm64.dmg`, open it, drag
Kingfisher to Applications, double-click. An installed 1.1.8–1.2.1 is
offered 1.2.2 through Sparkle's own window (_Kingfisher → Check for
Updates…_); an installed 1.1.0–1.1.7 is offered it by the engine those
shipped with (the release carries `latest-mac.yml` for it).

## Verification

The exact bytes the landing offers — size, SHA-256, build number and
commit — are in `src/release/macos-download.json`; `npm run
desktop:public:verify -- --landing --full` downloads them from GitHub
and checks the hash, the signature and the stapled ticket. The
commands run for this release and their results are recorded in
[`docs/reports/phase-72-handover.md`](../reports/phase-72-handover.md).
