# Kingfisher 1.4.3 — what ChessBase for Mac shows, and what using it turned up

Release notes, 2026-10-03. The comparison behind the list, with the evidence
for every number, is
[`chessbase-mac-comparison-2026-10-03.md`](../product/chessbase-mac-comparison-2026-10-03.md).

## New

- **Rating classes in the Explorer.** Under the move table: pick a rating
  class and the moves are re-read for it — games, share, white/draws/black,
  White's score — with the position across all classes and each move's share
  year by year. Read from the reference pack's own histories, counting games
  that reached the position after each move by any move order, as the panel
  says.
- **Explorer moves on the board.** Hover a row to see the move as an arrow;
  turn on the arrow button to draw the most played moves, wider for the more
  played.
- **Library: Position and Annotations filters.** Find games whose main line
  reaches a position (paste a FEN or take the board's), by any move order; or
  games that are annotated or commented. Both can be saved as queries.
- **Players and tournaments** on every collection's page: counts, and lists of
  players (score, years) and tournaments (newest first) that open the Library.
- **Download online games** (Databases): anyone's public games from Lichess
  or Chess.com, newest first, into My games.
- **Costly moves** in Preparation: the engine reads an opponent's newest games
  and counts the moves that gave the game away, by phase and colour, each one
  opening the game at that position.
- **Player photos** from Wikimedia Commons, with author and licence, on the
  preparation card and the player page.
- **Puzzles**: open the position on the analysis board while stuck (the
  attempt counts as unsolved).

## Fixed

- Chess960 and other variant games, and games whose `[FEN]` Kingfisher cannot
  read, are no longer imported as standard games replayed from the standard
  start; the import summary says how many were left out and why. Games an
  earlier version imported that way stay until you delete them; a Lichess
  export names them in the event ("Chess960 …"), so a Library search for
  Chess960 finds them.
- Explorer rating and year filters are no longer sent to sources that cannot
  apply them, and no surface claims they were applied.
- A position search in the Library, and saved queries with a move symbol or a
  "variations too" position, list every game they count.
- Review's tabs fit at laptop width; Openings separates thousands; a living
  player's roster card says Born.

## Data and privacy

Player photos are fetched from wikidata.org, commons.wikimedia.org and
Wikimedia's image host when a preparation report or player page is opened for
a titled player; nothing is stored, and the privacy page says so. Online-game
downloads use the Lichess and Chess.com public APIs, as account sync already
did. No schema change: a 1.4.2 profile opens unchanged, and one new preference
(`explorerBoardArrows`) defaults to off.

## Not in this release

DGT boards (no board to test against), ChessBase's video courses, magazines,
shop, corpora and cloud services, and any measured comparison with ChessBase
for Mac, which is not yet released.
