# Launch kit — Kingfisher 1.4.3

Draft copy for the current public release: Kingfisher 1.4.3 on the web and
macOS (Apple Silicon, macOS 13 or later, Developer ID signed and notarised).
This kit contains no user counts, endorsements or claims of complete ChessBase
parity. Check [`marketing-facts.md`](../product/marketing-facts.md) before posting.

## Description

Kingfisher is a local-first chess research workstation for serious players:
analysis, studies, opening research across separately labelled sources, native
engines, personal databases, repertoire, review and training. It is free and
open source under the MIT licence. Local study does not require an account.
Optional online features contact their named services; the website's disclosed
page-view and performance analytics do not run in the Mac application.

## Release announcement draft

> Kingfisher 1.4.3 adds Explorer rating classes and board arrows, Library
> position and annotation filters, collection players and tournaments, public
> game downloads from Lichess and Chess.com, Preparation's Costly moves,
> licensed Wikimedia player photos, and analysis help from a stuck puzzle.
>
> Stockfish 18 runs in the browser. The Apple Silicon application offers real
> native Stockfish, Stormphrax, Viridithas, Halogen, PlentyChess and Lc0 engines,

## Scope and limitations

Research is opt-in under Layout. Five-player usability observations are still
pending. This release does not claim full Firefox/WebKit certification or a
verified Windows, Linux or Intel Mac package. Portable backup/restore moves
local work between profiles; cross-device cloud Sync is not active. Version
1.0.0 predates the updater and needs manual replacement from a DMG.
