# Kingfisher 1.5.2 — puzzle move marks and unsaved-work safety

Puzzles mark each move on the board, on the square it landed on, as Lichess
and Chess.com do: a red cross while a wrong move stands, before it is taken
back; a green tick on a right move until the opponent replies; and the move
that solves keeps its tick. The opponent now replies after 600 ms instead of
350 ms, so the tick is seen.

An analysis nobody has saved is never replaced without a way back. Opening
the Scoresheet moves it to a tab of its own first. When the "+" beside Save,
a Library game, a search hit or any other replacement takes the board, the
analysis is kept as a tab of its own, “Unsaved analysis”, which survives a
reload, and a short notice says so. Before this, those actions dropped the
analysis silently.

When a browser cannot start the multi-threaded Stockfish build, analysis falls
back to the single-threaded build instead of reporting “Engine error”, and the
engine panel shows the single thread it runs with.

The install page's macOS-floor test no longer hard-codes a release's floor;
master's unit suite was red on it after 1.5.1.

The macOS download is `Kingfisher-1.5.2-arm64.dmg`, build 1179, Developer ID
signed and notarised by Apple, published 2026-10-14 and verified byte for
byte. Installed copies of 1.1.8 or later are offered it by _Check for
Updates…_. Validation is recorded in
[the 2026-10-14 report](../reports/2026-10-14-stream-hardening.md).
